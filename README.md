# pingdrop-site

Static support and privacy policy pages for the Ping Drop app, served by GitHub Pages at
<https://pingdrop.adams.is>.

- `/`: landing page
- `/support/`: App Store **Support URL**
- `/privacy/`: App Store **Privacy Policy URL**

Plain HTML and CSS, with no build step. `.nojekyll` makes Pages serve the files as they are. `CNAME`
sets the custom domain.

The app's source code is in a separate private repository.
